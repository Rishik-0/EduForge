# EduForge 🔥

> "Where knowledge is forged, not scrolled."

EduForge is a clean, distraction-free educational platform designed to deliver high-quality videos from trusted YouTube channels. By removing algorithmic recommendations and low-value content, EduForge transforms endless scrolling into focused, intentional learning.


## 🔗 Live Demo

You can check out the live, deployed version of the platform here:  
 **[EduForge Live Website](https://edu-forge-b7331zjig-saharsh-baijus-projects.vercel.app/)**


## 🚀 Features
* **Curated Channels:** High-quality educational content filtered from verified creators.
* **Zero Distractions:** Clean UI focused entirely on the video content without sidebar rabbit holes.
* **Serverless Backend:** Powered by a lightweight Google Apps Script API configuration for seamless data handling.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, CSS
* **Backend:** Google Apps Script (Web App API)
* **Hosting/Deployment:** Vercel

## ⚙️ Project Structure
* `src/` - Core React frontend components, styling, and application logic.
* `google_apps_script.js` - The backend service script handling data operations and API logic.
* `.env.example` - Template for necessary environment variables (e.g., API endpoints).
